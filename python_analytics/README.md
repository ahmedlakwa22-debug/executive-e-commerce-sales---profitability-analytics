# E-Commerce Sales & Profitability Analytics in Python (Pandas + Streamlit / Dash)

This directory contains the complete Python data analysis project for `ecommerce_sales_data__2__6f7ed651.csv`:

## Files
- `analysis_engine.py`: Data engineering and statistical analysis engine using `pandas`, `numpy`, `scipy`, and `statsmodels`.
- `streamlit_app.py`: Interactive 3-page dashboard built with **Streamlit** and **Plotly**.
- `dash_app.py`: Alternative 3-page dashboard implementation built with **Plotly Dash**.
- `requirements.txt`: Required Python dependencies.

## Running Locally
```bash
pip install -r python_analytics/requirements.txt

# 1. Run CLI statistical analysis:
python python_analytics/analysis_engine.py

# 2. Launch Streamlit 3-page dashboard:
streamlit run python_analytics/streamlit_app.py

# 3. Or launch Plotly Dash 3-page dashboard:
python python_analytics/dash_app.py
```
